StudyBuddy

StudyBuddy is a beginner-friendly e-learning platform for web development. It offers bite-sized lessons, interactive quizzes, and small projects to help learners quickly build practical skills in HTML, CSS, and JavaScript.

#Features

1.Interactive quizzes after each lesson

2.Short, hands-on lessons (10–20 minutes)

3.Small portfolio projects

4.Beginner-friendly and responsive

#Tech Stack

*HTML5
*CSS3
*JavaScript (minimal)
