HTML Basics

Understand the foundation of web pages: tags, elements, and structure.

Lesson 1: What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create and design web pages. HTML describes the structure of a web page using elements like <h1>, <p>, <img>.

Example: 

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>

Lesson 2: Common Tags

  • <h1> - <h6>: Headings
  • <p>: Paragraph
  • <a>: Links
  • <img>: Images
  • <div>: Division/container
